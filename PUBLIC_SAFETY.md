# Public safety and permission

Before first upload, check the entire packet, screenshots, metadata and Git author/email settings. Do not submit secrets, cookies, account recovery codes, real inboxes, school details, personal documents, faces, grades or private employer data. Only fictional course data is appropriate.

The instructor explains public visibility, AI-provider processing, student ownership and the equivalent private route before collecting work. For minors, the instructor verifies applicable account-age requirements and school/guardian arrangements privately. No public consent forms, dates of birth or identity documents. A checkbox is not a substitute for that process.

Publication is optional for assessment. If public submission is not appropriate, show the packet locally to the instructor or transfer through the cohort's approved private channel. The instructor uses the same rubric and feedback process. Do not make a public PR as a request for privacy.

Public technical feedback is about the artifact, not the learner. Keep scores, enrollment records, accommodations and disciplinary comments private. Do not use public leaderboards or infer ability from submission speed.

Automated scans are limited: they cannot reliably identify personal data, image metadata or all credentials. Git history, forks, notifications and downloads may preserve deleted content. If something leaks, stop sharing, rotate affected secrets, notify the instructor privately, and follow GitHub's sensitive-data removal guidance. Do not repeat the sensitive text in a bot comment or log.

Setting `public_safe: true` attests you have inspected the packet and have permission to publish it. `ai_review_consent: true` separately permits instructor-approved processing of the packet's **text** by the configured AI provider. Leave it false for human-only review; there is no assessment penalty. `store: false` is used for Responses API calls, but is not a promise of zero provider retention. The instructor must disclose the actual provider/account data policy before requesting consent.
